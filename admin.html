🎧 Panel del press kit

Se configura una sola vez en este dispositivo. Los datos quedan guardados solo en este navegador.

Cómo sacar el token

  1. GitHub → tu foto → Settings → Developer settings
  2. Personal access tokens → Fine-grained tokens → Generate new token
  3. Repository access: Only select repositories → elegí el repo del press kit
  4. Permissions → Contents: Read and write
  5. Generate, copiá el token y pegalo arriba

Editá lo que quieras y tocá Publicar. En 1–2 minutos lo ve todo el mundo. Si dejás una sección vacía, no se muestra en el sitio. Ver el sitio
